# Operação e Pedidos

## Fluxo pretendido

1. Cliente escolhe o produto.
2. Carrinho calcula subtotal.
3. Cliente informa endereço e pagamento.
4. Pedido é registrado.
5. Pagamento é aprovado.
6. Estoque é baixado.
7. Pedido é separado e enviado.
8. Código de rastreio é comunicado.
