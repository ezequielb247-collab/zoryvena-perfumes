# Imagens oficiais dos produtos

Adicione somente imagens fornecidas ou autorizadas pelo fornecedor/marca.

Formato recomendado: WebP, fundo claro ou transparente, entre 900 e 1400 px.

Use o ID do produto como nome do arquivo, por exemplo:

- `lattafa-asad.webp`
- `afnan-9pm.webp`
- `lattafa-yara.webp`

Depois, no painel administrativo ou em `assets/js/products.js`, preencha o campo `image` como `assets/products/lattafa-asad.webp`.
